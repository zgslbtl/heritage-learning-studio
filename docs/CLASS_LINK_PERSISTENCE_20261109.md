# 后台班级链接保留

日期：2026-11-09（Asia/Shanghai）。

## 使用

每次生成的链接都显示在对应班级记录中，并有独立的复制按钮。生成其他班级链接不会覆盖
已有地址；刷新、关闭页面或重新登录后仍可查看。有效链接按班级及生成时间列出。
重新生成会撤销原地址并新增一个地址；撤销后的记录保留状态，不再显示可复制地址。

升级前的随机链接继续按原哈希验证；原始token无法从哈希恢复，管理员可重新生成一次。

## 持久化与权限

迁移`0017_recoverable_class_links`只向`class_entry_links`增加可空的`token_scheme`列，
不修改既有链接哈希，不改变班级、参与者、内容、协议或互评语义。

新链接使用独立版本前缀，将链接UUID与班级ID作为消息，以服务器已有的
`ANON_CODE_PEPPER`计算HMAC-SHA256，并进行URL安全编码。数据库存token哈希和派生版本，
不存原始token；管理员列表按记录重建地址并核对哈希。服务器pepper须保持不变，
与既有分组和匿名访问码的运维要求一致。派生版本不匹配或密钥变化时不返回错误地址。

`GET /api/admin/class-links`需要管理员会话，响应设置`Cache-Control: private, no-store`。
学生及未登录请求不能查看列表；公开解析接口仍只返回班级元数据。
前端从管理员API恢复链接，不依赖浏览器localStorage或最近一次生成结果。

## 部署与回退

上线前备份数据库、变更源码及当前API/Caddy镜像。仅更新链接相关的7个源码文件，
不覆盖服务器OSS适配、图片交付和其他业务改动；数据库容器和数据卷保留。
API启动时执行新增列迁移，随后更新静态页面。

如需回退，保留数据库及新列。较早镜像不含0017迁移文件时，回退启动命令直接运行uvicorn，
避免旧镜像的Alembic因无法识别较新的版本号而中止。旧代码仍可验证新链接已有的token哈希，
但不再支持从后台恢复完整地址。备份中提供镜像标签和回退Compose覆盖配置。
