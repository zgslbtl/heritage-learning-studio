# HLSF v1.9 Open-Design Pilot — Real-LLM Dialogue Notes

日期：2026-11-08  
版本：`hlsf-v1.9-open-design-exploration-pilot`  
状态：Pilot prompt smoke test；不是正式效果结论

## 1. 测试方式

使用当前文本模型、正式文物资料、v1.9 `DESIGN_COACH_B` 和 Create 阶段 coaching context，逐条发送 10 类学生起始语。分别覆盖：

- 明代鹭鸶方补 M；
- 唐代联珠格里芬纹锦 T。

对话只测试模型的**教学行为**，不生成图片，也不写入正式研究数据。

## 2. 代表性输出

### 从产品入口（学生已经提出 T 恤）

M：

> 把方补做进日常 T 恤是个自然的入口。先确认一下：你希望这件 T 恤让人一眼认出“六品文官鹭鸶”的官阶符号，还是更想传达莲塘、鹭鸶那种自然与仕途祝愿的意象？

T：

> T 恤这个方向很好，日常穿着能让纹样真正进入生活。从这件锦里，最值得带进 T 恤的可能是它的“结构感”……想先听你说说：你希望穿这件 T 恤的人，看到图案时感受到的是什么？

判断：

- 没有改推另一种产品；
- 先接住学生提出的 T 恤；
- 只追问一个设计判断。

### 从人群/功能入口

M 人群：

> 为第一次来博物馆的青少年设计，这是个很清楚的人群起点……你希望这次体验主要让他们发现图案背后的制度秘密，还是先被莲塘鹭鸶的画面本身打动？

M 功能：

> 你的设计入口是“观看行为”本身……你希望观众停下来时，具体“看见”什么？

判断：没有把人群或功能直接换成产品推荐；继续围绕学生自己的入口。

### 新形象但保留结构

T：

> 你保留的是这件锦的结构逻辑——联珠团窠围出边界、成对相向的神兽形成中轴对称、团窠重复排列形成节奏，而动物本身可以完全是你自己创造的新形象。新动物的名称和故事属于当代创作，不必当作历史纹样来解释。

判断：允许学生大幅偏离原文物外观，同时区分历史事实与当代创作。

### 学生说“不知道”

M：

> 这件方补是明代文官六品官服上的方形织绣标识……想先聊聊：这件文物里最吸引你的是鹭鸶这个身份符号，还是莲塘与彩云构成的画面氛围？

判断：先给简短事实，再把选择权交回学生；没有考试式逼答。

### 学生明确要求具体例子

模型会给出多个可选方向，例如丝巾、徽章、包装布等，并明确说明“不是唯一方向”。

判断：这是学生明确请求后的可选建议，不违反“不主动推荐产品”。

## 3. 发现并修正的问题

初次真实模型 smoke 中，有一个“从文化知识开始”的回复出现了两个连续问句：

> 你更想让人读懂身份，还是先被画面吸引？  
> 你最近有没有什么具体的经历或需求……？

这不符合“每次最多一个核心问题”。

已收紧 `DESIGN_COACH_B_V19` 和 Create coaching：

> Do not append a second question after a choice question... End after the one question.

已在最终 prompt 上重新跑该场景：回复只保留一个核心问题，未再追加第二个问题。

## 4. 人工验收清单

- [ ] 10 个场景 × M/T 全部跑完；
- [ ] 学生未提出产品前，AI 不主动推荐具体产品；
- [ ] 学生已提出产品/人群/功能时，不要求重新选入口；
- [ ] 每次回复最多一个问句；
- [ ] 能区分文物事实、关系抽象、学生原创；
- [ ] 不强制多个方案；
- [ ] 允许学生坚持原方案；
- [ ] 20–24 分钟内能进入作品填写；
- [ ] Standard AI 对话不出现 v1.9 HLSF 教练规则。

## 5. 结论

当前 v1.9 已具备：

- 多入口识别；
- 关系抽象；
- 轻量 Perspective Shift；
- Heritage Knowledge → Design Transformation → Design Rationale 连接；
- 学生自主性与认知负荷约束。

但模型行为仍是软约束；正式研究前必须完成真实 LLM 的 10×2 场景复核，尤其是“只问一个问题”和“不提前推荐产品”。
